# Fitto Club-ის ადმინი — როგორ გამოვიყენოთ

მისამართი: `https://fitto.club/admin`. მუშაობს ტელეფონიდან, ტაბლეტიდან და კომპიუტერიდან. ყველაფერი, რასაც შეინახავთ, მაშინვე ჩნდება საიტზე: გადატვირთვა და ლოდინი არ არის.

## შესვლა

1. გახსენით `/admin/login`, შეიყვანეთ ლოგინი და პაროლი. ინტერფეისის ენა (ქართული ან რუსული) იქვე აირჩევა და დამახსოვრდება.
2. **პირველი შესვლა.** გთხოვენ მოიფიქროთ საკუთარი პაროლი (მინიმუმ 10 სიმბოლო) და მიუთითოთ სახელი. სახელი ჩანს ცვლილებების ისტორიაში: „ოთარმა შეცვალა აბონემენტი „სტანდარტული““.
3. დაგავიწყდათ პაროლი? მფლობელი გადააყენებს მას **მომხმარებლების** განყოფილებაში და გადმოგცემთ დროებითს. თუ თავად მფლობელს დაავიწყდა — მისწერეთ დეველოპერს.
4. ხუთი არასწორი ცდის შემდეგ შესვლა 15 წუთით იბლოკება.

## ეკრანი „დღეს“

- **სტატუსი**: ღიაა თუ არა კლუბი ახლა და რომელ საათამდე. ითვლება სამუშაო საათებითა და განსაკუთრებული დღეებით.
- **ყურადღებას საჭიროებს**: სია იმისა, რაც გასასწორებელია. ყოველი პუნქტი საჭირო ფორმის ბმულია. როცა ყველაფერი რიგზეა, ბლოკი ასეც ამბობს.
- **დღევანდელი ჯგუფური**, **სწრაფი მოქმედებები** („შეფასების დამატება“, „განსაკუთრებული დღე“) და **ბოლო ცვლილებები**.

ეკრანის ქვედა ნაწილში განყოფილებების პანელია: დღეს, განრიგი, შეფასებები, მწვრთნელები და „სხვა“ (ჯგუფური, აბონემენტები, მასაჯი, საათები, ისტორია, პროფილი, გასვლა).

## ხშირი ამოცანები

### შეფასების დამატება Google Maps-იდან
1. დააკოპირეთ შეფასების ტექსტი Google Maps-ის აპში.
2. „დღეს“ → **შეფასების დამატება**.
3. ჩასვით ტექსტი. ენა თავად განისაზღვრება ანბანით; თუ შეცდა, დააჭირეთ საჭიროს.
4. შეიყვანეთ ავტორი, შეფასება (ნაგულისხმევად 5), თვე, შეფასების ბმული. მონიშნეთ მწვრთნელები, რომლებზეც არის.
5. ჩართეთ „მთავარ გვერდზე“, თუ გინდათ საიტის პირველ ეკრანზე ნახვა.
6. **შენახვა**. შეფასება უკვე საიტზეა: ბმული „საიტზე ნახვა“ გაჩვენებთ სად.

### ვარჯიშის სხვა დროზე გადატანა
1. **განრიგი** → აირჩიეთ დღე ზედა ჩანართით.
2. დააჭირეთ ვარჯიშს ბადეში → შეცვალეთ დაწყება ან დღე → **შენახვა**. დაბრუნდებით ბადეში, შეცვლილი სლოტი გამოკვეთილია.
3. ბადის ცარიელი უჯრა „პლუსია“: დააჭირეთ, რომ ამ დროზე ახალი სლოტი დაამატოთ.
4. ვარჯიშების კვეთა დაშვებულია (კლუბში რამდენიმე ზონაა), მაგრამ წყვეტილი ხაზით ჩანს.

### დღესასწაული ან შემოკლებული დღე
1. „დღეს“ → **განსაკუთრებული დღე**.
2. აირჩიეთ თარიღი. „მთელი დღე დაკეტილია“ ნაგულისხმევად ჩართულია; გამორთეთ და მიუთითეთ საათები, თუ დღე შემოკლებულია.
3. შენიშვნა („დღესასწაული“) არასავალდებულოა, საიტზე საათების გვერდით ჩანს.
4. **შენახვა**. საიტზე სტატუსი ამ დღეს „დაკეტილია“-ს აჩვენებს.

კვირის ჩვეულებრივი საათები იცვლება **სხვა → საათები**-ში.

### აბონემენტის ფასის შეცვლა
1. **სხვა → აბონემენტები** → საჭირო აბონემენტი.
2. ცხრილში „ვადები და ფასები“ შეასწორეთ ფასი. ცარიელი ფასი ნიშნავს, რომ ეს ვადა არ იყიდება და საიტზე დამალულია.
3. **შენახვა**. ფასი ერთდროულად შეიცვლება აბონემენტების გვერდზე, მთავარზე და საძიებო სისტემების მონაცემებში.

„ერთჯერადი ვიზიტი“ აბონემენტების სიის პირველი სტრიქონია.

### ახალი მწვრთნელი
1. **მწვრთნელები** → **დამატება**.
2. შეავსეთ სახელი სამ ენაზე (ლათინურით, კირილიცით, მხედრულით) და აღწერა. შეგიძლიათ არასრული **მონახაზი** შეინახოთ: ის საიტზე არ ჩანს.
3. პირველი შენახვის შემდეგ გამოჩნდება ბლოკი **ფოტო**: აირჩიეთ ფოტო ტელეფონიდან და დააჭირეთ „ატვირთვა“. პორტრეტი თავად მოიჭრება 4:5 ფორმატში. თუ თავი კადრში არ არის, დააჭირეთ გადახედვას სახის ადგილზე და „ფოკუსის შენახვა“.
4. მონიშნეთ ენები, მიმართულებები, პერსონალური ვარჯიშის ფასი.
5. ჩართეთ **გამოქვეყნებულია** და შეინახეთ. თუ რომელიმე ენაზე ცარიელია, ფორმა გეტყვით, რა აკლია, და მონახაზად შენახვას შემოგთავაზებთ.

### მწვრთნელი წავიდა
გახსენით მწვრთნელი, გამორთეთ **გამოქვეყნებულია**, შეინახეთ. მისი გვერდი დაიხურა, სიაში არ არის, ძველი მისამართი მწვრთნელების სიაზე გადამისამართებს. თუ ის ვარჯიშებს ატარებდა, „დღეს“ შეგახსენებთ ვარჯიშს მწვრთნელი შეუცვალოთ.

## რას ნიშნავს „წაშლა“

არაფერი არ იკარგება სამუდამოდ. წაშლილი ჩანაწერი ქრება საიტიდან და სიიდან, მაგრამ დევს ბმულის „წაშლილების ჩვენება“ უკან და **ისტორიაში**. ღილაკი **აღდგენა** აბრუნებს მას ყველა მონაცემით. განსაკუთრებული დღეები და განრიგის სლოტები მაშინვე იშლება, ისინი ისტორიაშია ჩაწერილი.

## ისტორია

**სხვა → ისტორია**: ვინ, როდის და რა შეცვალა. ფილტრი ჩანაწერის ტიპით. წაშლებს — ღილაკი „აღდგენა“.

## მომხმარებლები (მხოლოდ მფლობელი)

**სხვა → მომხმარებლები**: რედაქტორის დამატება, პაროლის გადაყენება, დაბლოკვა. ახალ მომხმარებელს დროებითი პაროლი ერთხელ ეჩვენება. გადაეცით პირადად; პირველ შესვლაზე ადამიანი საკუთარს დააყენებს.

## ექსპორტი (მხოლოდ მფლობელი)

**სხვა → ექსპორტი** ჩამოტვირთავს საიტის ყველა მონაცემს ერთ JSON ფაილად. ეს თქვენი მონაცემებია და ყოველთვის თქვენთანაა.

## ვის მივმართოთ

გვერდების ტექსტები, მისამართი, ტელეფონი, ზონების ფოტოები და კლუბის აღწერა დეველოპერის მეშვეობით იცვლება. ადმინის კითხვებზეც მას მისწერეთ.
