## 1. Цель и CTA

**Цель сайта: человек приходит в клуб.** Сайт не продаёт онлайн и не собирает заявки через форму.

- **Главный CTA:** прийти на **первый бесплатный визит**. Кнопка ведёт к блоку «Как добраться»: адрес, карта, кнопки маршрута (Google Maps и Apple Maps), часы работы и видео «как найти вход».
- **Вторичные CTA** для тех, у кого есть вопросы:
  - позвонить: `tel:+995595031885`;
  - написать в директ Instagram: `https://ig.me/m/fitto.club_tbilisi`.
- **Форм нет.** Поэтому Resend, Turnstile, `generate_lead` и Measurement Protocol не нужны: интеграций ноль, по §3 это по умолчанию.
- **Аналитика** по §11: tag гейтится `GTM_ID`, Consent Mode v2. Ключевые события:
  - `contact_click` (`method`: `tel` | `instagram`; `location`);
  - `select_content` для «Проложить маршрут» (`cta_label=directions`);
  - `language_switch`;
  - `page_not_found`.

  Конверсия сайта — клик на маршрут или звонок; реальный визит в клубе сайт не видит.

- **Акции на сайте не показываем.** Единственное исключение — персональная тренировка в подарок к абонементу, это поле абонемента (§4).

## 2. Языки

`en` (эталон), `ru`, `ka`. Язык задаётся префиксом URL, `/` перенаправляет по cookie, затем по `Accept-Language`.
- Грузинский: без `uppercase`, отдельный шрифт с поддержкой мхедрули, подключается только на `/ka/`.
- Русский: заглавные через `text-transform` тоже запрещены (§5), капс для заголовков выбирается на уровне шрифта или дизайна.
- Каждую локаль вычитывает агент, для которого язык родной (§5). Для `ka` желательно ещё и живой носитель.
- **Тема только тёмная** (решение бренда). Переключателя темы нет, контраст WCAG AA проверяется для одной темы.

## 4. Админка (CMS, §13)

Редактирует клуб сам. Хранилище: **SQLite на Railway volume** (один инстанс, 1–2 редактора, медиа — фото тренеров). Миграции goose в двух диалектах.
Через админку: разовое посещение, абонементы, тренеры и теги, групповые занятия, массаж, часы работы, отзывы.
Всё остальное (тексты страниц, адрес, телефон, зоны, история клуба) — типизированные данные в бинарнике, меняются через деплой.

### Разовое посещение
| Поле | Тип | Локализуется |
|---|---|---|
| Цена | integer, GEL (минорные единицы) | нет |

### Тип абонемента
| Поле | Тип | Локализуется |
|---|---|---|
| Название | string | **да** |
| Текстовое описание | text | **да** |
| Цены по срокам: месяц / 3 месяца / 6 месяцев / год | integer GEL, каждая необязательная | нет |
| Заморозка по срокам: месяц / 3 / 6 / год | int, дней или недель, необязательное | нет |
| PT в подарок | bool (флаг «1 персональная тренировка в подарок») | нет |
| Порядок сортировки, видимость | int, bool | нет |

Пример: «Стандартный» 180/490/870/1550, заморозка —/1/2/3 нед., PT в подарок. «Семейный (цена за человека, от 2 человек)» 150/410/670/1350, та же заморозка. Пустая цена значит, что такой срок не продаётся, и он скрывается.

### Тренер
| Поле | Тип | Локализуется |
|---|---|---|
| Имя | string | **да** (латиница, кириллица, мхедрули: «Irakli Nikolaishvili / Иракли Николаишвили / ირაკლი ნიკოლაიშვილი») |
| Фото | загрузка (ресайз + WebP при загрузке, EXIF удаляется) | alt-текст **да** |
| Instagram | handle, необязательный | нет |
| Языки | набор `ka`/`en`/`ru`/`es`/`de`, бейджи на карточке и фильтр в списке | нет |
| Описание | text | **да** |
| Теги направлений | many-to-many к справочнику тегов | название тега **да** |
| Цена персональной тренировки | integer + валюта (GEL по умолчанию; у Эвана цена в USD), необязательное; флаг «от» (у Влада «от 90») | нет |
| Slug | string, генерируется из латинского имени, редактируемый | нет |
| Опубликован | bool, галочка | нет |
| Порядок | int | нет |

**Публикация тренера:**
- **Опубликован:**
  - `/{lang}/coaches/{slug}` отдаёт 200;
  - тренер есть в списке, в `sitemap.xml` (все три локали и hreflang-кластер) и в JSON-LD;
  - на него ссылаются групповые занятия.
- **Снят с публикации**, в том числе после soft-delete:
  - `/{lang}/coaches/{slug}` отдаёт **`301` на `/{lang}/coaches`** той же локали. Цепочек редиректов нет: переход в один шаг, сразу на канонический URL списка.
  - Тренер исчезает из списка, из `sitemap.xml` и из JSON-LD.
  - Групповые занятия показывают его имя без ссылки.
  - `<lastmod>` списка тренеров обновляется, так как список изменился.
  - Ответ с 301 отдаётся с `Cache-Control: no-cache`: браузеры по умолчанию кешируют 301 навсегда, и без этого заголовка после повторной публикации посетитель продолжал бы улетать на список.
- **Повторная публикация:** URL снова отдаёт 200 и возвращается в sitemap со свежим `<lastmod>`, поисковик переобходит страницу.
- **Смена slug:** старый slug хранится в таблице истории и отдаёт 301 на новый. Ссылки из соцсетей и поиска не ломаются.
- **Незнакомый slug** (такого тренера никогда не было): обычный 404 с локализованной страницей, **не** редирект. Редирект любого мусорного URL на список Google считает soft 404.

Почему 301, а не 302: снятие с публикации в клубе обычно значит, что тренер ушёл. 301 говорит поисковику убрать URL тренера из индекса и передать его сигналы странице списка. 302 держал бы в индексе страницу, которой нет. Если тренер вернётся, повторная публикация восстановит страницу (см. выше).

**Справочник тегов** (редактируемый): набор массы, снижение веса, мобильность, осанка, реабилитация, функциональный тренинг, кеттлбелл, бодибилдинг, пауэрлифтинг, единоборства (BJJ), подготовка к соревнованиям, питание, работа с детьми, бег… Изначальный набор соберу из специализаций 13 тренеров.

### Групповое занятие
| Поле | Тип | Локализуется |
|---|---|---|
| Название | string | **да** |
| Описание | text | **да** |
| Тренер | ссылка на тренера, необязательная | нет |

| Порядок, видимость | int, bool | нет |

Стартовые данные: Full Body (Пн/Ср/Пт, 10:00 и 19:00), Kettlebell с Анастасией (Ср 14:00, Вс 12:00), беговой клуб Just Run с Эваном (Пт 08:00, 10 GEL). Актуальность подтвердить у клуба. JSON-LD: `Course` + `CourseInstance` (`courseSchedule`).

**Недельное расписание** (решение 27.09.2026). В админке есть отдельный раздел «Расписание»: сетка «дни недели × время», где видны все слоты всех занятий сразу. Слот можно добавить кликом по ячейке (выбрать занятие, время начала, длительность), перетащить или удалить. Это другой вид на те же данные — слоты групповых занятий, а не отдельная сущность; в карточке занятия слоты по-прежнему редактируются списком. Пересечения слотов разрешены (в клубе несколько зон), но подсвечиваются. На сайте эта же сетка стоит **первой** на `/{lang}/classes`: на мобильном — список по дням, начиная с сегодняшнего (по времени Тбилиси), на десктопе — таблица на неделю.

### Массаж
| Поле | Тип | Локализуется |
|---|---|---|
| Услуга | string | **да** |
| Длительность | int, минуты | нет |
| Цена | integer GEL | нет |

Описание специалиста и видов массажа — текст страницы в бинарнике. Специалист (Анастасия Новикова) может быть связан с записью тренера. JSON-LD: `Service` + `Offer`.

### Часы работы
| Поле | Тип | Локализуется |
|---|---|---|
| День недели ×7 | открытие, закрытие или «выходной» | нет |
| Особые дни | дата + часы или «закрыто», необязательно (праздники) | примечание **да** |

Выводятся в шапке «Как добраться», в футере и в JSON-LD `OpeningHoursSpecification` из одной записи. Статус «Открыто сейчас» считается на сервере по времени Тбилиси.

### Админка — общее
Сессии, bcrypt, CSRF, rate-limit на логин, `/admin` в `noindex` и `robots`. Сохранение перерисовывает и пережимает затронутые страницы без деплоя. Soft-delete, журнал изменений, экспорт в JSON. Бэкапы volume и репетиция восстановления до запуска. На передаче клуб получает инструкцию на русском (и грузинском?).

## 5. Визуальное направление

- **Бренд** (из [materials/CONTENT.md §7](materials/CONTENT.md)):
  - цвета: чёрный, неоновый оранжевый `#FF4401`, белый;
  - логотип-штанга и «варсити»-буквы;
  - панда в логотипе;
  - паттерн из дуг;
  - дружелюбный тон с юмором.
- Векторный логотип: `materials/brand/vector/`.
- **Панда — только часть логотипа, не маскот** (решение 27.09.2026). Панда не появляется отдельно: без поз и наклеек, её нет в 404, пустых состояниях, иллюстрациях и паттернах. Используется только в составе логотипа и как фавикон/иконка приложения (`fitto-panda-mark.svg`). Советы из `research/style-references.md` про маскот-систему (Duolingo, Mailchimp) и панду-наклейку к нам **не применяются**.
- **Выбранное направление: «Orange Room»** (решение 27.09.2026, описание в [research/style-references.md](research/style-references.md) §C.2) с поправками проекта:
  - **Смена фона по секциям.** Крупные секции чередуют сплошной оранжевый `#FF4401` с узором колец и чёрный. На чёрном идут фото зала, тренеры и прайсы. Светлых (off-white) секций нет, так как тема только тёмная.
  - **Узор колец** — главный графический приём:
    - фон оранжевых секций;
    - вырезы фото в форме кольца или полукольца;
    - акценты на стыках секций.
  - **Панда только в логотипе:** наклеек-панд из исходной концепции не будет.
  - **Типографика по Instagram-стилю:** геометрические заглавные с разрядкой для заголовков. Тяжёлый блочный шрифт («CLUB», Arial Black) — только для цифр и цен, например крупных цен абонементов.
  - **«Прыгающая» типографика** (The Gym Vienna): одно-два слова на страницу, не больше, например «FREE» в «первый визит бесплатно».
  - **Фото:** реальные, в цвете, в вырезах-кольцах на оранжевом или в полную ширину на чёрном. Мем-стилистика рилсов — подписанными кадрами, умеренно.
  - **Риск: «оранжевая усталость».** Чередовать с чёрными секциями, не заливать оранжевым подряд больше одной секции.
- **Instagram-стиль клуба — обязательная часть дизайна** (решение 27.09.2026). Реконструирован в вектор: `materials/brand/vector/pattern/`, генератор `materials/brand/build_pattern.py`, исходные обложки в `materials/brand/instagram-style/`.
  - **Поле:** сплошной оранжевый `#FF4401`.
  - **Узор:** сетка толстых колец тон-в-тон `#FF571A`. У каждого кольца нет верхне-левой четверти (срезы на 12 и на 9 часов). Внешний радиус ≈ ½ шага, соседи касаются; внутренний ≈ 0,26 шага. Узор бесшовный, одна плитка (`pattern-tile*.svg`) — готовый CSS `background`.
  - **Акценты** — это те же ячейки сетки, подсвеченные другим тоном или вырезом. Их 2–5 на экран, они не повторяются рядом:
    - кольцо с узким зазором на 12 часов, `#FFECE5`;
    - кольцо с широким зазором, `#FFDBCE`;
    - правое полукольцо, `#FFA081`;
    - четверть-дуга, `#FF7341`;
    - белая гиря (кольцо с ручкой).
  - **Типографика на оранжевом:** белые заглавные в геометрическом гротеске с широкой разрядкой (≈0,2 em), подзаголовок строчными («FIRST VISIT FREE / in Fitto Club»). Похоже на Futura или Avenir; веб-кандидат с кириллицей — Jost (OFL). Грузинскую пару подберём, капс в `ka` запрещён (§5), разрядка остаётся.
  - **Контраст:** белый на `#FF4401` = 3,45:1 — это только крупный текст (≥ 24 px, или ≥ 18,7 px жирным). Основной текст на оранжевом — чёрный (6,1:1) либо выносится на тёмный фон. Оранжевый текст на чёрном (6,08:1, на графите `#1A1A1A` 5,04:1) проходит AA и для основного текста.
- **Исследования** готовы:
  - [research/style-references.md](research/style-references.md): референсы и три концепции;
  - [research/competitors-tbilisi.md](research/competitors-tbilisi.md): 15 сайтов клубов Тбилиси и скриншоты в `research/competitor-shots/`.
  - Главный вывод: тёмный hero с горячим красным или оранжевым акцентом и узким капсом (Cage, TNT, Snap, Oktopus) — это типичный местный шаблон. Instagram-стиль клуба с оранжевыми полями и узором колец от него уходит. Близко к нашему оранжевому ещё Fitpass (`#e6441f`), так что графический язык колец — главное отличие.
- Запреты из §10 чек-листа: градиент на чёрном в hero, glassmorphism, сетка иконок, счётчики, агрессивное «JOIN NOW», стоковые фото.
