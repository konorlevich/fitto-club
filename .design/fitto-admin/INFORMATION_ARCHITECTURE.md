# Information Architecture: админка FITTO CLUB (`/admin`)

Бриф: [DESIGN_BRIEF.md](DESIGN_BRIEF.md). Модель данных: [BRIEF.md §4](../../BRIEF.md). Решения приняты 27.09.2026 (design flow, фаза 3).

Ранжирование задач по частоте (из брифа и интервью), оно определяет нижнюю панель и первый экран:

| Частота | Задача | Где решается |
|---|---|---|
| Несколько раз в неделю | Добавить отзыв из Google | Отзывы → «Добавить», быстрое действие на «Сегодня» |
| Раз в неделю | Перенести или добавить слот занятия | Расписание → ячейка |
| Раз в месяц | Изменить цену абонемента, PT, массажа | Абонементы / Тренеры / Массаж → запись |
| Раз в месяц | Праздник: особый день | Часы → особые дни, быстрое действие на «Сегодня» |
| Раз в квартал | Новый тренер с фото, уход тренера | Тренеры → «Добавить» / переключатель «опубликован» |
| Редко | Пользователи, экспорт, смена пароля | «Ещё» |

Глубина навигации: **не больше трёх уровней** (раздел → запись → вложенная форма). Единственный третий уровень — слот занятия и особый день.

## Site Map

- Вход `/admin/login` (GET форма, POST вход) · Выход `POST /admin/logout`
  - Первый вход владельца `/admin/setup` — обязательная смена ENV-пароля; пока не пройден, все остальные пути редиректят сюда
- **Сегодня** `/admin` — статус, занятия сегодня, «требует внимания», последние изменения, быстрые действия
- **Расписание** `/admin/schedule` — сетка дни × время; `?day=1…7` выбирает день на телефоне (по умолчанию сегодня)
  - Новый слот из ячейки `/admin/classes/{id}/slots/new?day=&start=&back=/admin/schedule` — форма слота с предзаполнением; занятие выбирается на этом же экране, если `{id}` не задан: `/admin/schedule/new?day=&start=`
- **Отзывы** `/admin/reviews` — список, сначала новые; `?deleted=1` показывает удалённые
  - Новый `/admin/reviews/new`
  - Отзыв `/admin/reviews/{id}` (GET форма, POST сохранить)
  - `POST /admin/reviews/{id}/delete`, `POST /admin/reviews/{id}/restore`, `POST /admin/reviews/{id}/move?dir=up|down`
- **Тренеры** `/admin/coaches` — список в порядке сайта, черновики помечены; `?deleted=1`
  - Новый `/admin/coaches/new`
  - Тренер `/admin/coaches/{id}` — форма; после сохранения превью карточки
    - Фото `POST /admin/coaches/{id}/photo` (загрузка), `POST /admin/coaches/{id}/photo/focus` (точка фокуса), `POST /admin/coaches/{id}/photo/delete`
  - `POST …/{id}/delete`, `…/restore`, `…/move`
  - Теги `/admin/tags` — справочник: список с кнопками порядка, inline-добавление. _Сборка: путь `/admin/tags`, а не `/admin/coaches/tags`: `net/http.ServeMux` не различает `/coaches/{id}/delete` и `/coaches/tags/{slug}`. Ссылка на теги остаётся в разделе тренеров._
    - Тег `/admin/tags/{slug}` — название × 3 локали; `POST …/delete` (тег снимается с тренеров)
- «Ещё» (лист, не страница)
  - **Занятия** `/admin/classes` — список; `?deleted=1`
    - Новое `/admin/classes/new`
    - Занятие `/admin/classes/{id}` — форма со списком слотов
      - Слот `/admin/classes/{id}/slots/{n}` и `/admin/classes/{id}/slots/new` — общая форма с сеткой; `?back=` возвращает туда, откуда пришли
      - `POST …/slots/{n}/delete`
    - `POST …/{id}/delete`, `…/restore`, `…/move`
  - **Абонементы** `/admin/memberships` — первая строка «Разовое посещение — 20 GEL», ниже типы абонементов; `?deleted=1`
    - Разовое посещение `/admin/memberships/single` — одно поле
    - Новый `/admin/memberships/new`
    - Абонемент `/admin/memberships/{id}`
    - `POST …/{id}/delete`, `…/restore`, `…/move`
  - **Массаж** `/admin/massage` — список услуг; `?deleted=1`
    - Новая `/admin/massage/new` · Услуга `/admin/massage/{id}` · `POST …/delete`, `…/restore`, `…/move`
  - **Часы** `/admin/hours` — неделя одной формой + особые дни списком
    - Особый день `/admin/hours/special/new`, `/admin/hours/special/{date}`; `POST …/delete`
  - **История** `/admin/history` — лента; `?entity=coach|review|…`, `?page=2`
  - **Пользователи** `/admin/users` — только владелец
    - Новый `/admin/users/new` · Пользователь `/admin/users/{id}` · `POST …/reset` (временный пароль), `POST …/block`, `POST …/unblock`
  - **Экспорт** `POST /admin/export` — только владелец, отдаёт JSON-файл
  - **Профиль** `/admin/profile` — имя, пароль, язык UI, тема
  - **Открыть сайт** — внешняя ссылка на `/{lang}/` в новой вкладке
  - Выход
- Служебные: `/admin/static/admin.css`, `/admin/static/admin.js` (или общий `/static/` с хэшами, как у сайта); 403 / 404 / 500 внутри оболочки; `POST /admin/theme` и `POST /admin/lang` для переключателей без JS

`/admin` и всё под ним: `noindex`, `Disallow` в `robots.txt` (уже есть), `Cache-Control: no-store`, `Vary: Cookie`.

## Navigation Model

- **Primary navigation** (нижняя панель на телефоне, боковая колонка от 1024 px). Ровно 5 позиций на телефоне: **Сегодня · Расписание · Отзывы · Тренеры · Ещё**. Порядок по частоте задач. Активный раздел `aria-current="page"` + подпись жирнее и полоска сверху, не только цвет. Иконок нет или один простой глиф на позицию (решается в фазе 6); подпись обязательна всегда.
- **Secondary navigation.** Внутри разделов — контекстные ссылки, не второй ряд табов:
  - Расписание: табы дней (только на телефоне) + ссылка «Занятия списком»;
  - Тренеры: ссылка «Теги» в шапке списка;
  - Абонементы: строка «Разовое посещение» первой в списке;
  - Часы: особые дни ниже недели на той же странице;
  - Списки с soft-delete: ссылка-фильтр «Показать удалённые (N)» в конце списка, появляется только если N > 0.
- **Utility navigation.** Лист «Ещё» (`<details>` снизу на телефоне; на десктопе эти пункты просто продолжают боковую колонку под разделителем): Занятия, Абонементы, Массаж, Часы, История, — разделитель — Пользователи (владелец), Экспорт (владелец), Профиль, Открыть сайт, Выход. Переключатели темы и языка — в профиле и внизу боковой колонки.
- **Mobile navigation.** Нижняя панель, `position: sticky; bottom: 0`, `padding-bottom: env(safe-area-inset-bottom)`, высота 56 px + safe-area. Лист «Ещё» открывается над панелью, закрывается тапом мимо, Esc или повторным тапом; без JS работает как `<details>`. Шапка страницы: заголовок раздела слева, одно действие справа («Добавить» или «Сохранить»), кнопка «Назад» в шапке на страницах второго и третьего уровня (ссылка на родителя или `?back=`).
- **Роли.** Один вход и одна структура для владельца и редактора. Редактор не видит пункты «Пользователи» и «Экспорт»; прямой заход отдаёт 403 внутри оболочки.

## Content Hierarchy

### Сегодня `/admin`
1. **Статус клуба сейчас** — «Открыто до 22:00» или «Закрыто, откроемся в 08:00», сегодняшний день и часы, ссылка «Часы». Первый вопрос ресепшена и быстрая проверка, что особый день сработал.
2. **Требует внимания** — счётчик и список ссылок, в порядке: опубликованное с пропуском перевода → занятие с тренером, снятым с публикации → тренер опубликован без фото → тренер-черновик → факты, ждущие клуба (`content.Pending`, с пометкой «подтвердите разработчику»). Блок не рендерится, если пунктов нет: вместо него одна строка «Всё в порядке».
3. **Занятия сегодня** — список слотов дня с временем, названием и тренером, каждый — ссылка на форму слота с `?back=/admin`. Пусто → «Сегодня групповых нет».
4. **Быстрые действия** — две кнопки: «Добавить отзыв», «Особый день». Именно эти две, потому что они начинаются не из списка, а из внешнего повода (пришёл отзыв, объявили праздник).
5. **Последние изменения** — пять строк истории, ссылка «Вся история».

### Расписание `/admin/schedule`
1. **Табы дней** (телефон) с выделенным сегодня; на десктопе — заголовки колонок.
2. **Сетка** 07:00–23:00 по получасу. Слот занимает ячейки по длительности, внутри название и тренер; пересечение — штриховая рамка + строка «пересекается с …». Пустая ячейка — ссылка «+» с доступным именем «Добавить слот, Пн 19:00».
3. **Ссылки** под сеткой: «Занятия списком», «Открыть расписание на сайте».

### Списки (Отзывы, Тренеры, Занятия, Абонементы, Массаж)
1. **Кнопка «Добавить»** в шапке справа.
2. **Строки** в порядке сайта (для отзывов — по дате, новые сверху): название · вторичная строка · значение справа · шеврон. Пометки «черновик» / «скрыт» текстом слева от значения. Кнопки «↑ ↓» у сортируемых списков — в строке, справа от значения, только на ≥ 768 px; на телефоне — в форме записи, блок «Порядок».
3. **Пустое состояние** — фраза + «Добавить».
4. **«Показать удалённые (N)»** в конце.

### Форма записи (все сущности)
1. **Шапка**: «Назад», заголовок (имя записи или «Новый …»), «Открыть на сайте →» если запись опубликована.
2. **Сводка ошибок** (только после неуспешного POST).
3. **Группы полей** в порядке: Основное (локализуемые названия) → специфичное (цена, слоты, языки, теги, фото) → Публикация (переключатель, порядок) → опасная зона («Удалить» вторичной кнопкой, без подтверждения).
4. **Панель сохранения**, прилипшая внизу.

### Часы `/admin/hours`
1. Неделя: семь строк, каждая «день · открытие · закрытие · выходной».
2. Особые дни: ближайшие сверху, прошедшие скрыты за «Показать прошедшие».
3. Ссылка «Как это выглядит на сайте» → `#visit`.

### История `/admin/history`
1. Фильтр по сущности (чипы).
2. Лента: «Отар · вчера 18:42 · изменил абонемент „Стандартный“», ссылка на запись; у удалений — кнопка «Восстановить».
3. Пагинация «Раньше».

## User Flows

### Добавить отзыв из Google (самый частый)
1. Редактор копирует текст в приложении Google Maps, открывает `/admin` на телефоне.
2. Тап «Добавить отзыв» (быстрое действие) → `/admin/reviews/new`.
3. Вставляет текст; язык подсказан по письменности (JS) или будет вычислен при сохранении. Вводит автора, вставляет ссылку, оценка по умолчанию 5, месяц — текущий, отмечает тренера.
4. «Сохранить» → POST.
   - Ошибка (нет текста или автора) → форма с введёнными значениями, сводка сверху.
   - Успех → редирект `/admin/reviews` с flash «Сохранено · Открыть на сайте →». Сайт уже отдаёт новую главную (если «на главной») и страницу тренера.

### Перенести занятие на другое время
1. `/admin/schedule` → таб нужного дня (или сразу сегодня).
2. Тап по слоту → `/admin/classes/{id}/slots/{n}?back=/admin/schedule?day=3`.
3. Меняет начало 19:00 → 19:30. «Сохранить».
   - Новое время пересекается с другим слотом → сохраняется, в сетке слот с пометкой пересечения (пересечения разрешены).
   - Успех → редирект на `back`, слот подсвечен 2 с.

### Праздник: закрыть клуб на день
1. `/admin` → «Особый день» → `/admin/hours/special/new`.
2. Дата, переключатель «закрыто» (скрывает поля часов), примечание × 3 локали (необязательное).
3. «Сохранить» → `/admin/hours` с flash. На «Сегодня» в этот день статус покажет «Закрыто».

### Изменить цену абонемента
1. «Ещё» → Абонементы → строка «Стандартный — от 129 GEL/мес».
2. Форма: таблица сроков, меняет «месяц: 180 → 160».
3. «Сохранить» → список с flash «Сохранено · Открыть на сайте →». Публичные `/memberships` и главная перерисованы.

### Новый тренер с фото
1. Тренеры → «Добавить» → `/admin/coaches/new`. Имя × 3, описание × 3, языки, теги, PT. Переключатель «опубликован» выключен по умолчанию.
2. «Сохранить» → редирект на `/admin/coaches/{id}` (запись создана как черновик). Появляется блок «Фото».
3. Выбирает фото с камеры → превью (JS) → «Загрузить» → POST → сервер: sniff, лимит, EXIF, кроп 4:5 по центру, WebP → форма с превью карточки.
4. Тап по превью ставит точку фокуса → «Сохранить фокус» → превью пересчитано.
5. Включает «опубликован» → «Сохранить».
   - Пусто KA → ошибка у поля «Чтобы опубликовать, заполните описание на грузинском» + кнопка «Сохранить как черновик».
   - Успех → страница тренера на сайте отдаёт 200, он в списке и sitemap.

### Тренер ушёл
1. Тренеры → строка тренера → переключатель «опубликован» выкл → «Сохранить». URL на сайте отдаёт 301 на список, занятия показывают имя без ссылки.
2. На «Сегодня» появляется пункт «Занятие Kettlebell ведёт тренер, снятый с публикации» → ссылка на форму занятия → сменить тренера.
3. Позже «Удалить» в форме → список с flash «Удалено · Восстановить». Запись видна за фильтром «Показать удалённые».

### Первый вход владельца
1. Мы задаём `ADMIN_OWNER_LOGIN` и `ADMIN_OWNER_PASSWORD` в ENV.
2. `/admin/login` → вход по ENV-паролю принимается **только пока в базе нет пароля владельца**.
3. Редирект на `/admin/setup`: новый пароль дважды, имя, язык UI. Пока не сохранено, все пути ведут сюда.
4. Сохранено → пароль в базе (bcrypt), ENV-пароль больше не работает → `/admin`.

### Владелец заводит редактора
1. «Ещё» → Пользователи → «Добавить»: имя, логин, роль «редактор».
2. «Сохранить» → экран с временным паролем один раз («покажите его коллеге, он сменит при входе»).
3. Редактор входит → обязательная смена пароля (тот же `/admin/setup` в режиме «смена») → `/admin`.

## Naming Conventions

Метки даны на русском (UI), с грузинским эквивалентом в бандле. Один термин на понятие.

| Понятие | Метка в UI | Заметки |
|---|---|---|
| Первый экран | Сегодня | Не «Главная», не «Дашборд»: экран про сейчас |
| Сетка слотов | Расписание | Раздел; на сайте то же слово |
| Групповое занятие | Занятие | Не «класс», не «курс». Мн. ч. «Занятия» |
| Слот расписания | Слот | «Пн 19:00–20:00». Внутри занятия — «Слоты» |
| Тип абонемента | Абонемент | Раздел «Абонементы»; срок внутри — «Срок» (месяц, 3 месяца…) |
| Drop-in | Разовое посещение | Как на сайте |
| Заморозка | Заморозка, нед. | Единица всегда в подписи |
| Персональная тренировка | PT | Как на сайте («PT от 90 GEL»); в KA тоже латиницей |
| Coach | Тренер | Не «инструктор» |
| Тег направления | Тег | Раздел «Теги»; чипы в форме |
| Языки тренера | Говорит на | Заголовок группы чекбоксов |
| Review | Отзыв | Поля: Автор, Текст, Язык, Ссылка, Оценка, Месяц, Тренеры, На главной |
| Massage service | Услуга | Раздел «Массаж», строки — услуги |
| Visible / Published | Опубликован (тренер), Виден (остальные) | Два слова намеренно: у тренера есть своя страница и редирект, у остальных — только строка в списке |
| Черновик | Черновик | Пометка невидимой записи в списке |
| Soft-delete | Удалить / Удалённые / Восстановить | Никогда «архив» |
| Hours | Часы | Раздел; «Выходной» для закрытого дня |
| Special day | Особый день | Не «праздник»: бывает и укороченный день |
| Changelog | История | Не «журнал», не «лог» |
| Actor | Имя пользователя как есть | «Отар изменил…» |
| Roles | Владелец, Редактор | |
| Save | Сохранить | Единственный глагол сохранения; нет «Обновить», «Применить» |
| After save link | Открыть на сайте → | Всегда в новой вкладке с пометкой |
| Order buttons | Выше / Ниже | Доступное имя «Выше: Стандартный» |
| Attention block | Требует внимания | Пусто → «Всё в порядке» |
| More sheet | Ещё | |
| Theme | Тема: Светлая / Тёмная / Как в системе | |
| UI language | Язык интерфейса | Отдельно от «Языки» тренера |

## Component Reuse Map

| Компонент | Используется на | Различия в поведении |
|---|---|---|
| Оболочка (шапка + нижняя панель / боковая колонка) | Все страницы после входа | На `/admin/login` и `/admin/setup` — нет панели и колонки, только логотип |
| Шапка страницы | Все | Уровень 1: заголовок + «Добавить»; уровни 2–3: «Назад» + заголовок + «Открыть на сайте» |
| Список строк | Отзывы, Тренеры, Занятия, Абонементы, Массаж, Теги, Пользователи, особые дни | Кнопки порядка только у сортируемых; «черновик» только там, где есть флаг; отзывы без порядка, по дате |
| Форма записи + панель сохранения | Все формы | Группа «Публикация» отсутствует у отзыва, часов, пользователя; «Опасная зона» отсутствует у часов и профиля |
| Поле × 3 локали | Тренер, Занятие, Абонемент, Услуга, Тег, особый день (примечание) | Обязательность: только при включённом «опубликован/виден» |
| Форма слота | Из сетки и из занятия | Из сетки: выбор занятия виден, `back` на сетку; из занятия: занятие фиксировано, `back` на занятие |
| Сетка расписания | `/admin/schedule` | Один день на телефоне, неделя на десктопе. Публичная сетка на `/classes` — другой шаблон, но та же функция данных `WeekGrid()` |

## Content Growth Plan

- **Отзывы** растут быстрее всего: 48 в Google сейчас, десятки в год. Список по дате, новые сверху, 30 на страницу, пагинация «Раньше», фильтр по тренеру `?coach=`. Поиска нет: по имени автора хватает прокрутки.
- **История** растёт с каждым сохранением. 50 на страницу, фильтр по сущности, старше года не показывается в UI (в базе остаётся).
- **Тренеры, занятия, абонементы, массаж, теги**: 3–20 записей, растут медленно. Один экран без пагинации; кнопки порядка достаточно до ~20 записей.
- **Особые дни**: 5–15 в год. Прошедшие скрыты за ссылкой, не удаляются.
- **Пользователи**: 2–3. Список без пагинации.
- **Фото**: одно на тренера, старое удаляется при замене; derivatives на volume. Без медиатеки.
- **Новая локаль** (`LOCALES`): у каждого поля × 3 появляется четвёртая строка, «Требует внимания» перечисляет все опубликованные записи с пропуском. Структура не меняется.

## URL Strategy

- **Паттерн:** `/admin/{section}[/{id}[/{sub}[/{n}]]]`. Секции во множественном числе латиницей, как на сайте: `coaches`, `classes`, `reviews`, `memberships`, `massage`, `hours`, `history`, `users`. Исключения-одиночки: `schedule`, `profile`, `export`, `login`, `setup`.
- **Без локали в пути.** Язык UI — cookie `admin_lang` (ru | ka), по умолчанию `ru`; смена через профиль или `POST /admin/lang`.
- **Динамические сегменты:** `{id}` — хранимый ID записи (`c-…`, `r-…`, `m-…`), не slug; `{n}` — порядковый номер слота внутри занятия; `{date}` особого дня — `2026-01-07`; `{slug}` только у тегов (у тега slug и есть ключ).
- **Действия — только POST**, глагол в конце пути: `/delete`, `/restore`, `/move`, `/photo`, `/photo/focus`, `/reset`, `/block`. Ответ всегда 303 на страницу, откуда пришли (`?back=` или родитель). GET на такой путь — 405.
- **Query-параметры:** `?day=` (сетка), `?deleted=1` (показать удалённые), `?entity=` и `?page=` (история), `?coach=` (отзывы), `?back=` (возврат из вложенной формы; принимаются только пути, начинающиеся с `/admin/`), `?day=&start=` (предзаполнение слота). Никаких персональных данных в query.
- **Новые записи:** `…/new` для GET-формы и POST-создания; после создания 303 на `…/{id}`, чтобы появились зависимые блоки (фото у тренера, слоты у занятия).
- **Ошибки:** 403 для чужой роли, 404 для незнакомого ID (включая удалённые вне `?deleted=1`, кроме прямого перехода из истории, где удалённая запись открывается только для чтения с кнопкой «Восстановить»), 405 для GET на действие.
- **Статика админки:** `/static/admin.css`, `/static/admin.js` через тот же хэшированный `staticHandler`, что у сайта.
